# MAIP JetBrains Plugin

Machine identity and cryptographic receipts for IntelliJ, PyCharm, GoLand, WebStorm.

## Install

Settings > Plugins > Search **MAIP Truthlocks**

## Get Started

1. Settings > Tools > Truthlocks > Enter email > Register
2. Right-click file > Protect with Truthlocks

No website needed. Free: 100 protections/month.

## Features

- Protect files with cryptographic proof
- Auto-receipts on commit and save
- 10 algorithms (Ed25519, ES256, ES384, ES512, RS256-PS512)
- Trust dashboard tool window
- Agent identity management
